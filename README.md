
# 🍕 Food Delivery Application

A Food Delivery Application developed using **Core Java**, **JDBC**, **Servlets**, **JSP**, **HTML**, **CSS**, **JavaScript**, and **MySQL**. This application allows users to browse food items, place orders, and manage their accounts, while administrators can manage food items and customer orders.

---

## 📖 About the Project

The Food Delivery Application is designed to simplify the online food ordering process. Customers can register, log in, browse available food items, add them to the cart, and place orders. The application also provides an admin module for managing the menu and orders.

---

## ✨ Features

### User
- User Registration and Login
- Browse Food Menu
- Add Items to Cart
- Place Orders
- View Order History
- Update Profile

### Admin
- Admin Login
- Add Food Items
- Update Food Details
- Delete Food Items
- Manage Customer Orders

## ⚙️ Installation

### Prerequisites

- Java JDK 8 or above
- Apache Tomcat
- MySQL
- Eclipse IDE (or any Java IDE)
- Git

### Steps

1. Clone the repository

```bash
git clone https://github.com/yourusername/Food-Delivery-Application.git
```

2. Import the project into Eclipse.

3. Create a MySQL database.

4. Import the SQL file into MySQL.

5. Update the database username and password in the JDBC connection file.

6. Deploy the project on Apache Tomcat.

7. Open your browser and run:

```
http://localhost:8080/Food-Delivery-Application
```
